# Case Closed AI

**Don't guess. Investigate.**

Case Closed AI is a desktop investigation prototype with an animated detective-inspired interface, guided troubleshooting, an evidence board, and a local casebook.

The source code and installation guidance are in [`case-closed-ai/`](case-closed-ai/README.md).

**Status:** prototype. It does not independently detect viruses, automatically repair device issues, or run a connected AI model.

After GitHub Pages is enabled, the browser preview can be hosted at `https://ahmirgrahams-gif.github.io/Case_closed/`.
